## Verified acceptance cases

Specification basis. Resolve an existing owning services section and return its root without writing runtime data.

| Case | Check | Behavior |
| --- | --- | --- |
| ` NODE-PROCESS-REFUSAL ` | source refusal | The data root resolver refuses a missing owner and leaves the path absent. |
| ` NODE-PROCESS-QUICKSTART ` | consumer example | An installed caller selects its owning section through an environment input without creating a data directory. |

Runtime requirement. ` >=22 `
